{#- ONE THING INSIDE A FOLDER, shown as a place rather than a word. Expects, set with set_global before the include: pl_title what she called it pl_href where it goes pl_here its colocated_path — the folder it sits in, which is a real path for a section and for a page alike. `assets` is not: a section spells them as urls with the language in front, and `/en/…/01.jpg` is not a file anybody can resize. pl_assets its files, for the names only THE FACE. Same order as the desk icon, so a folder does not wear one picture in one place and another picture in the other: a file called `icon.*` if she dropped one in, otherwise the first photograph, otherwise nothing and the name carries it alone. `poster.*` is a film's still and never the face.
