{#- ONE THING INSIDE A FOLDER, laid along the route. Expects, set with set_global before the include: pl_title what she called it pl_href where it goes pl_here its colocated_path — the folder it sits in, which is a real path for a section and for a page alike. `assets` is not: a section spells them as urls with the language in front, and `/en/…/01.jpg` is not a file anybody can resize. pl_assets its files, for the names only pl_extra its [extra], for the pinning below PINNED, LIKE A FRIDGE. Each photograph takes its own width and its own place left or right of the line, declared per FILE in the folder's front matter — the same shape `[extra.alt]` already uses, so there is one convention to learn rather than two: [extra.width] "01.jpg" = 48 # per cent of the page (a number, no %) [extra.offset] "01.jpg" = -12 # per cent off the centre, + is right [extra.angle] "01.jpg" = -2 # degrees, how it hangs All three optional, and independent: an angle may be declared without a width. Declare none and the stylesheet gives the photograph a place from a repeating rhythm, so a folder nobody has arranged still looks pinned rather than stacked in a column. EVERY PICTURE IT HOLDS, rather than one face for the whole thing. A folder of four photographs arrived as a single cropped thumbnail with its name underneath: that said a folder existed and nothing about the work inside it. Each photograph is its own stop now, and all of a thing's stops lead to the same place. It is also the honest way to put more pictures on the page. These are photographs already in the site and already looked at; drawing new ones means new random draws, and a draw comes back with whatever it comes back with — which is why placeholders.py carries a map of seeds chosen by hand. NOT her photographs, and never a stop: `icon.*` is the face on the desk, `poster.*` is a film's still, `wallpaper.*` is the ground a desk used to stand on. A thing with no picture at all is real — an empty folder, a project holding only a document — and it must stay reachable, so it arrives as a stop wearing nothing but its name. -#} {%- set_global pl_shown = 0 -%} {%- for a in pl_assets -%} {%- set leaf = a | split(pat="/") | last -%} {%- set stem = leaf | split(pat=".") | first -%} {%- set ext = leaf | split(pat=".") | last | lower -%} {%- if ext in config.extra.image_types and stem != "poster" and stem != "wallpaper" and stem != "icon" -%} {%- set src = pl_here ~ leaf -%} {%- set shape = get_image_metadata(path=src) -%} {%- set small = resize_image(path=src, width=900, op="fit_width", format="webp", quality=78) -%} {%- set_global pin = "" -%} {%- if pl_extra.width and pl_extra.width[leaf] -%} {%- set_global pin = pin ~ "--w:" ~ pl_extra.width[leaf] ~ ";" -%} {%- endif -%} {%- if pl_extra.offset and pl_extra.offset[leaf] -%} {%- set_global pin = pin ~ "--x:" ~ pl_extra.offset[leaf] ~ ";" -%} {%- endif -%} {%- if pl_extra.angle and pl_extra.angle[leaf] -%} {%- set_global pin = pin ~ "--r:" ~ pl_extra.angle[leaf] ~ ";" -%} {%- endif -%} {{ pl_title }} {%- set_global pl_shown = pl_shown + 1 -%} {%- endif -%} {%- endfor -%} {%- if pl_shown == 0 -%} {{ pl_title }} {%- endif -%}
