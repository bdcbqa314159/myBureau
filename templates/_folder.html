Expects two globals, set before the include: fw the section this window shows fw_depth how far below the current desk it is (1 or 2) Zola 0.23's template engine has no macros, so a global plus an include is the only way to pass an argument. These are opened with show() and not showModal(), so several folders can be open at once and the bureau keeps working underneath — see "folder windows" in desk.ts. -#}
